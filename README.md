# 审美入门手册 — Vibe Coding 时代的设计素养

> 从认知科学到设计实践，系统培养界面审美的判断力与表达力。

**[在线阅读 →](https://aesthetic-handbook.vercel.app/)**

---

## 为什么需要这本手册

Vibe coding 让每个人都能通过 AI 快速生成界面，但「能生成」不等于「能判断好坏」。这份手册帮助混合团队（技术 + 非技术）建立共同的审美语言——**先学会看，再学会说**。

## 特色

- **有理论依据** — 每个原则都有认知科学和设计理论的支撑（格式塔、加工流畅性、Hick 定律等）
- **看得见差异** — 每个概念都有 CSS 渲染的 Good vs Bad 可视化对比
- **说得出来** — 建立精确的审美词汇，40 组「模糊表达 → 精确表达」对照表
- **AI Prompt 指南** — 如何给 AI 写出高审美的 UI prompt

## 技术栈

- [Next.js 15](https://nextjs.org/) App Router
- [Tailwind CSS 4](https://tailwindcss.com/)
- [Geist](https://vercel.com/font) 字体
- 部署于 [Vercel](https://vercel.com/)

## 本地运行

```bash
git clone https://github.com/BertramRay/aesthetic-handbook.git
cd aesthetic-handbook
npm install
npm run dev
```

打开 http://localhost:3000 查看。
